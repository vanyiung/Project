# KMNZ Resume Summary

## 一句话版本

使用原生 HTML、CSS 和 JavaScript 构建响应式多页面资料站。

## 50 字版本

使用原生 Web 技术开发 KMNZ 多页面资料站，实现成员展示、内容轮播、浅深色主题、账户原型、个人中心和媒体封面管理。

## 100 字版本

KMNZ 是原生 HTML、CSS 和 JavaScript 构建的响应式资料站，包含首页、成员详情、历程、登录注册、个人中心和歌回封面等 12 个页面。项目使用 localStorage 持久化主题与演示状态，支持可选 Firebase Auth 和封面代理配置，并完成 JavaScript 语法与本地链接检查。

## 详细版本

项目不依赖前端框架或构建工具，通过共享 CSS 和 JavaScript 组织多页面站点。主题模块处理系统偏好和本地持久化，公共脚本负责导航、轮播、成员渲染及认证分支，封面模块负责媒体链接解析和本地列表管理。认证在配置 Firebase 时使用云端服务，否则进入仅供演示的 localStorage 模式。

## 前端岗位版本

使用原生 HTML、CSS 和 JavaScript 构建响应式多页面站点，实现主题系统、动态成员卡片、轮播、可选 Firebase 认证和媒体封面管理，并完成脚本语法与站内链接检查。

## 答辩介绍版本

项目用于集中整理 KMNZ 的成员和历程资料。站点采用纯静态结构，便于直接部署；同时通过 JavaScript 增加主题、账户原型和媒体管理功能。项目重点是多页面一致性、渐进增强和外部服务可选配置。
