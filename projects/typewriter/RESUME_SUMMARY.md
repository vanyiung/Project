# TypeWriter Resume Summary

## 一句话版本

使用 AutoHotkey v2 开发 Windows 文本模拟输入工具，支持快捷键、延迟和输入速度配置。

## 50 字版本

面向禁止粘贴的输入场景，使用 AutoHotkey v2 开发 Windows 桌面工具，实现逐字符输入、延迟进度、自定义快捷键、托盘和开机自启。

## 100 字版本

TypeWriter 是使用 AutoHotkey v2 开发的 Windows 桌面输入工具。项目提供多行文本编辑、普通和延迟输入、自定义快捷键、输入速度、进度反馈、始终置顶、系统托盘及开机自启，并处理设置窗口在多显示器工作区内的居中和边界问题。

## 详细版本

项目使用 AutoHotkey v2 构建原生 Windows GUI，通过 `SendText` 将文本逐字符发送到当前焦点位置。设置模块支持运行时更新快捷键、延迟和速度，并在快捷键注册失败时恢复原配置；系统集成模块使用 INI 保存置顶偏好，通过当前用户注册表项控制开机自启。源码与可执行程序采用 MIT License 公开。

## 桌面工具岗位版本

使用 AutoHotkey v2 实现轻量 Windows GUI 工具，覆盖全局热键、系统托盘、注册表自启、INI 配置、多显示器窗口定位和逐字符输入控制。

## 答辩介绍版本

项目解决部分网页禁止粘贴时长文本输入效率低的问题。用户先在工具中准备文本，再通过按钮或快捷键触发模拟输入。工具支持延迟切换窗口、控制输入速度和显示进度，同时保持本地运行，不上传文本。
