# Visual Assistance System Assets

## 可保存内容

- 脱敏设备照片。
- 自制系统架构图。
- 脱敏演示截图。
- 比赛证书或公开成果截图。

## 命名规则

- `device-YYYYMMDD.png`
- `architecture-YYYYMMDD.png`
- `demo-sanitized-YYYYMMDD.png`
- `award-YYYYMMDD.png`

## 脱敏要求

不得包含路人可识别面部、地理隐私、账号凭据或未授权视频。

## 文件大小

图片建议不超过 2 MB，不提交大型视频和数据集。

## 版权要求

仅提交自有或明确可公开展示的素材。
