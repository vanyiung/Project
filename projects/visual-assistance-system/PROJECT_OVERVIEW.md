# 端侧视觉辅助出行系统

## 项目背景

面向辅助出行场景，探索在端侧设备上结合目标检测、语义分割、光流、相对深度和本地语音提示，提供环境感知能力。

## 解决的问题

- 在端侧设备上进行视觉感知。
- 将视觉结果转化为可理解的辅助提示。
- 探索边缘 AI 设备在出行辅助场景中的应用。

## 当前状态

已知使用 Raspberry Pi 5、Hailo-8 和 YOLOv8，并取得计算机设计大赛西北赛区一等奖、入围国赛。性能数字和完整验证记录待补充。

## 技术栈

- Raspberry Pi 5
- Hailo-8
- YOLOv8
- 目标检测
- 语义分割
- 光流
- 相对深度
- 本地语音

## 主要功能

- 目标检测。
- 语义分割。
- 光流分析。
- 相对深度估计。
- 本地语音提示。
