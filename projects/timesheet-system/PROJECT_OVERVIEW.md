# 员工工时系统

## 项目背景

员工工时系统用于记录部门、用户、项目、员工项目分配和工时填报等基础管理流程。

## 解决的问题

- 管理部门、用户和项目基础数据。
- 建立员工与项目的分配关系。
- 提供工时填报相关 REST API。
