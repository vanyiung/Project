# Privacy Checklist

提交前检查以下内容：

## Secret

- 没有密码、Token、API Key、Cookie、私钥。
- 没有真实数据库连接信息。
- 没有真实服务器后台地址或管理入口。
- 没有 `.env`、`application-local.yaml` 等本地配置。

## 个人隐私

- 没有身份证号、手机号、家庭住址。
- 没有私人邮箱或未经确认可公开的联系方式。
- 没有未脱敏成绩单、合同、证件或截图。
- 没有导师、同学或团队成员的私人联系方式。

## 项目数据

- 没有真实用户数据。
- 没有真实交易数据。
- 没有企业内部数据。
- 没有数据库备份、模型权重或大型数据集。

## 图片和素材

- 截图已脱敏。
- 控制台截图不包含凭据。
- 图片来源可说明或为自己制作。
- 大文件没有误提交。

## Git 检查

提交前查看暂存内容，确认只包含本轮作品集文档和安全素材。
