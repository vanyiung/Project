# Skills Evidence

## Java / Spring Boot

- QuantGuard 使用 Java 21 和 Spring Boot 实现 REST API。
- 员工工时系统使用 Spring Boot 构建后端接口。

## Vue / TypeScript

- QuantGuard 使用 Vue 3、TypeScript、Vite、Pinia、Element Plus 和 ECharts 实现前端。
- 员工工时系统使用 Vue 3、TypeScript、Vite、Pinia、Vue Router、Element Plus 和 ECharts 实现三角色工作台。

## JavaScript / Web

- KMNZ 使用原生 HTML、CSS 和 JavaScript 构建多页面响应式静态站点。
- KMNZ 实现浅深色主题、localStorage 状态、可选 Firebase 认证和媒体封面导入。

## AutoHotkey / Windows

- TypeWriter 使用 AutoHotkey v2 实现 Windows GUI、全局快捷键、系统托盘、注册表开机自启和 INI 偏好存储。

## Database

- QuantGuard 使用 MySQL 和 MyBatis-Plus，包含版本化迁移脚本和事务测试。
- 员工工时系统使用 MySQL 和 MyBatis。

## Testing

- QuantGuard 使用 JUnit 5、Mockito、MockMvc 和 Testcontainers MySQL。
- QuantGuard 使用 Playwright 覆盖 K 线交互、账户切换、硬删除和回本计算等浏览器流程。
- QuantGuard 已接入前后端 GitHub Actions。
- 员工工时系统前端已通过 TypeScript 与 Vite 生产构建。
- KMNZ 全部 JavaScript 文件通过 `node --check`，站内本地链接检查通过。

## Architecture

- QuantGuard 使用分层架构和明确业务边界。
- QuantGuard 采用 Spring Boot 后端与 Vue 3 前端的 monorepo 结构。
- 员工工时系统采用 Controller、Service、Mapper、Entity 分层，并按管理员、经理和员工划分页面流程。
- TypeWriter 将窗口、热键、托盘和输入控制集中在单文件桌面工具中。
- 作品集文档记录系统边界、模块划分、数据流和限制。
