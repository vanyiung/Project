# Project Descriptions

这里集中保存简历可用的项目描述。所有内容必须能被项目文档、源码仓库、比赛材料或测试记录支撑。

## QuantGuard 智衡量化交易与风控系统

### 一句话

基于 Java 21、Spring Boot、MySQL 和 MyBatis-Plus 开发本地模拟交易与风控后端，覆盖账户、组合、持仓、订单、成交、资金流水和事务测试。

### 简历条目

- 设计并实现本地模拟交易后端，采用 Controller、Service、Mapper、Entity、DTO 分层结构，完成模拟账户、投资组合、证券标的、持仓、风控、模拟订单、成交和资金流水模块。
- 使用 BigDecimal、事务、乐观锁和受影响行数检查处理资金冻结、成交结算和并发竞争，避免重复成交和资金状态不一致。
- 编写 JUnit 5、Mockito、MockMvc 和 Testcontainers MySQL 测试，并接入 GitHub Actions 验证普通测试和真实 MySQL 容器集成测试。

## 端侧视觉辅助出行系统

### 一句话

基于 Raspberry Pi 5、Hailo-8 和 YOLOv8 构建端侧视觉辅助出行系统原型，结合目标检测、语义分割、光流、相对深度和本地语音提示。

### 简历条目

- 参与端侧视觉辅助出行系统，使用 Raspberry Pi 5 和 Hailo-8 探索边缘 AI 部署。
- 结合 YOLOv8、语义分割、光流、相对深度和本地语音提示构建辅助感知流程。
- 项目获得计算机设计大赛西北赛区一等奖并入围国赛；性能数字待核验后补充。

## 员工工时系统

### 一句话

基于 Spring Boot、MySQL 和 MyBatis 实现员工工时管理 REST API，覆盖部门、用户、项目、员工项目分配和工时填报。

### 简历条目

- 使用 Spring Boot、MySQL 和 MyBatis 构建员工工时管理后端。
- 实现部门、用户、项目、员工项目分配和工时填报等基础业务模块。
- 提供 REST API，具体测试和上线状态待补充核验。
